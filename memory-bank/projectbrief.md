# Project Brief

`Market-Data-Lab` exists to manage historical market data acquisition, metadata, validation, storage, and reproducible usage.

It is responsible for:

- dataset identity and metadata;
- acquisition/update provenance;
- validation and audit records;
- preserving raw data semantics;
- documenting derived timeframe policy.

It is not responsible for:

- strategy logic;
- indicator definitions;
- production execution;
- committing machine-local paths.
